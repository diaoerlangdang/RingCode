6. 主题切换说明

主题 = 一套 token 取值集合。实现时维护两套 CSS 变量(如 data-theme="dark" / "light"),组件只引用变量名,不直接写死色值。新增主题只需新增一套 token 取值,无需改动组件代码(UI-008)。
