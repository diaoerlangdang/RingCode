## RingCode v0.4.5

本版本修复升级 Codex CLI 后无法滚动历史的问题，改善多个 Agent 同时运行时的会话列表表现，并支持以 Markdown 显示更新说明。

### Codex 终端滚动

- 适配 Codex CLI 0.161.0，恢复聊天输出的历史滚动。
- Codex 原版和分身在新建、继续、分叉会话时统一使用 `--no-alt-screen`，保留终端滚动历史。

### 会话列表与状态

- 修复 Codex、Antigravity 等多个 Agent 同时输出时，本机会话列表反复跳动的问题。
- 避免终端持续输出时重复检查历史目录，减少后台开销。
- 关闭会话的最后一个终端标签页后，运行中状态立即更新为“已中断”。
- 已结束、失败的状态继续保留；同一会话仍有其他终端运行时保持“运行中”。

### 更新说明

- GitHub Release Notes 按 Markdown 显示，支持标题、列表、加粗、代码块、表格和链接。
- 长更新说明可滚动查看，说明中的链接在系统浏览器打开。
- 渲染前清理不安全的 HTML 内容。

### 下载说明

- `RingCode-0.4.5-x64.exe`：Windows x64 安装版
- `RingCode-0.4.5-x64.zip`：Windows x64 免安装版

- TypeScript 类型检查通过，61 个测试文件、281 项测试全部通过。
- 真实 Codex CLI 输出验证历史滚动；真实 Electron 界面验证会话列表、关闭状态和 Markdown 更新弹窗。
