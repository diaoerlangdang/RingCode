## RingCode v0.5.0

本版本新增固定在底部的独立输入框和图片附件，浏览历史输出时仍可编辑草稿，并修复 Claude Code 继续会话后无法滚动的问题。

### 固定输入框与复制

- 支持 Claude Code、Codex CLI 及其分身，以及 Antigravity CLI（谷歌）和 OpenCode。
- 输入区固定在底部，支持 Enter 发送、Shift+Enter 换行和中文输入法；切换终端、分屏和重载保留各自草稿。
- 底部输入模式下，Ctrl+C 用于复制，取消任务使用“中断任务”按钮；提供“回到最新”和“原生终端操作”入口。
- 确认菜单自动恢复 CLI 按键操作，暂时暂停发送并保留草稿；菜单结束后恢复底部输入。
- 隐藏已识别的原生输入区、闪烁光标和重复输入提示，保留模型/模式信息及原生操作入口。

### 图片附件与缓存

- 支持粘贴截图、拖入或选择 PNG/JPEG，单张最多 10 MB；发送前可查看缩略图、放大和移除。
- 图片保存为本地副本，通过路径交给 CLI 读取；原图保持原样，图像理解由使用的模型与权限决定。
- 草稿和会话保存图片引用，关闭终端或重载后仍保留已发送图片；共享副本在所有引用释放后清理。
- 设置中可查看缓存占用、清理无引用副本；自动清理包含孤儿宽限期和删除失败重试。

### 终端滚动修复

- 修复 Claude Code 继续会话后没有滚动条、滚轮无效的问题。RingCode 启动的 Claude 及其分身采用传统渲染，兼容本地历史滚动和选区复制，保留彩色输出。
- 修复隐藏输入区挡住滚轮，以及滚动刷新可能造成输出错行的问题。
- 恢复会话和显示终端时检查滚动范围；Codex、谷歌 CLI 和 OpenCode 保留各自现有启动行为。

### 使用范围

- 原生输入区目前为视觉隐藏，原来的占位空间仍然保留。
- 普通 Shell、Hermes 和其他未适配的 CLI 继续使用原生输入。
