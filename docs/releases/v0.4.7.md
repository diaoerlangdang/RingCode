## RingCode v0.4.7

本版本增强 Markdown 阅读和编辑：流程图可直接显示，长文档可以按标题导航，编辑器与预览可以单独最大化。

### Markdown 图表与目录

- 支持 `mermaid` 代码块中的流程图、时序图等图表，本地渲染、按需加载。
- 预览内增加可折叠的文档目录，支持中文标题、重复标题、点击跳转和当前章节高亮。
- 单独预览与并排预览均可使用；并排模式默认收起目录。
- 图表随深浅主题变化。无效图表只显示当前图块的错误与源码，不影响整篇文档。
- 保留本地相对图片加载和 HTML 清理，普通代码块继续显示源码。

### 编辑器与预览最大化

- Markdown 编辑器和预览增加最大化、还原按钮，支持 `.md` 和 `.markdown`。
- 最大化期间保留未保存内容、编辑位置、原布局和运行中的终端进程。
- 切换到非 Markdown 文件时自动退出最大化，避免丢失还原入口。

### 下载说明

- `RingCode-0.4.7-x64.exe`：Windows x64 安装版。
- `RingCode-0.4.7-x64.zip`：Windows x64 免安装版。

### 验证情况

- 63 个测试文件、287 项测试全部通过。
- 新增真实 Electron 回归，覆盖图表、目录、主题、旧内容丢弃、图片加载和非 Markdown 预览。
- 真实 Monaco 编辑器与 ConPTY 进程验证最大化前后保持不变。
- Windows x64 ZIP 与 NSIS 安装包构建通过，ZIP 完整性检查和实际解压通过。
- 在隔离测试数据库中运行 ZIP 包内的生产页面、preload 和原生模块，验证离线图表、本地图片、125%/150% 缩放，以及窗口重载后会话数据保留。
- 产物校验值与具体范围见 `docs/发版打包.md` 的 v0.4.7 记录。

底部独立输入框、图片粘贴和 Ctrl+C 行为调整属于后续阶段，本版本尚未加入。
