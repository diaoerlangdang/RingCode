**产品目标**：一个窗口里完成文件管理器、编辑器、终端和多个 Agent，不必开系统终端、不必在 Agent 之间切窗口。Agent 用注册表接入：内置 Claude Code / Codex / Hermes；设置里可加自定义 CLI。

**结论**：v0.2 P0 缺口已补到可日常使用。仍弱的是按工作区隔离布局/打开文件（WSP-004/005）、另存为、工作区标签页、Skill Git 导入、应用更新检查。

## 二、2026-08-15 已修（对照审查 + v0.2 + 全量补齐）

上午一轮：TRM-006 孤儿终端、凭据不进渲染层、工作区白名单、transcript 节流、回收站、外链协议、Skill 50MB、文档版本对齐。

下午一轮（产品目标：集成工作台 + 可扩展 Agent）：

1. **Agent 适配器** — `src/lib/agents.ts`。新增内置 Agent 只追加一条；设置可添加自定义 CLI（AIT-009）。
2. **Hermes** — 内置第三 Agent；顶栏 / 启动栏 / 向导 / 历史筛选同步。
3. **Claude 危险启动** — 启动面板可选 default / Auto / `--dangerously-skip-permissions`。Hermes 对应 YOLO（`--yolo`）。
4. **配置方案编辑 UI**（AIT-004/006、CFG-001/002、ENV-004）— 命令、参数、模型、终端策略、环境变量、浏览 exe。
5. **会话记录** — 右栏查看正文、收藏/删除、按 Agent 筛选、磁盘历史含 Hermes 根目录。
6. **收藏/最近/重命名** — 左栏真数据；工作区与终端可重命名。
7. **文件** — 树形视图、拖入终端、复制路径/副本、fs.watch、外部修改冲突、面包屑跳转。
8. **编辑预览并排、终端分屏、快捷键自定义、Shell 类型**。

自测：`npm run typecheck` + `npm test`。
