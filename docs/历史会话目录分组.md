# 历史会话目录分组规格

> 状态：已确认，作为本轮实现与验收依据。  
> 日期：2026-08-19  
> 范围：右侧“本机会话 / 磁盘历史”的目录分组、排序、分页、搜索、刷新、展开状态和目录操作。

## 1. 背景

当前历史会话以平铺卡片展示：

- 本机会话先按收藏排序，再按 `lastActiveAt` 倒序；
- 磁盘历史按 JSONL `mtime` 倒序，但全局最多返回最近 50 条；
- 不同项目、目录和 Agent 的记录混在一个长列表中。

本轮将两个历史来源继续分开，但在各自 Tab 内采用统一的单层目录分组。分组不能只基于全局最近 50 条，否则较早目录会消失、统计也不准确。

## 2. 数据来源与时间定义

- **本机会话**：目录取 `Session.cwd`，更新时间取 `Session.lastActiveAt`。
- **磁盘历史**：目录取 `HistoryMatch.projectPath`，更新时间取原生 JSONL `mtime`。
- 已关联记录在两个 Tab 中可显示不同时间；不伪造统一时间。
- 无目录的记录归入固定的“未知目录”组。

Windows 路径分组时：

- 忽略大小写；
- 忽略末尾 `/` 或 `\`；
- 保留不同绝对路径下的同名目录；
- 工作区根目录和其子目录仍是不同组。

## 3. 目录组排序

顺序为：

1. 精确等于当前工作区根目录的组；
2. 当前工作区下的子目录组，按组内最近更新时间倒序；
3. 其他目录组，按组内最近更新时间倒序；
4. “未知目录”固定在最后。

没有当前工作区时，所有正常目录按最近更新时间倒序。

组内会话严格按更新时间倒序；收藏只显示星标，不影响顺序。不同 Agent 混合排列，由卡片标识和顶部 Agent 筛选区分。

## 4. 目录组展示

单层目录组头展示：

- 目录末级名称；
- 单行省略的完整路径，悬停可查看完整值；
- 会话数量；
- 最近更新时间；
- 当前工作区、子目录或“目录不可用”状态。

没有搜索或 Agent 筛选时显示总数，例如 `12`；存在筛选时显示 `命中数 / 总数`，例如 `3 / 12`。

窄右栏不构造完整文件系统树，不让长路径多行撑高组头。

## 5. 展开状态

默认规则：

- 当前工作区根目录组展开；
- 其他组折叠；
- 当前工作区没有历史时，展开最近更新的第一个正常目录；
- “未知目录”折叠。

本地与磁盘两个 Tab 分别持久化 `规范化完整路径 -> boolean` 的展开状态。目录移动或改名后视为新组，不做模糊迁移。

用户主动创建或切换会话时，可展开其目录；后台刷新和时间变化不得反复抢占展开状态。

搜索或筛选时：

- 隐藏无命中会话的目录；
- 自动展开命中目录；
- 用户可临时折叠；
- 清空筛选后恢复筛选前的持久化状态。

## 6. 搜索与筛选

同一搜索框支持：

- 会话标题；
- 会话正文；
- 目录名称；
- 完整路径。

路径或目录名称命中时，显示该目录下所有符合 Agent 筛选的会话；标题或正文命中时，只显示命中会话。

本地和磁盘历史都保留目录上下文，不退化为全局平铺结果。

## 7. 分页

两个 Tab 采用相同体验：

- 每个展开目录首次显示最近 30 条；
- 使用明确的“加载更多”按钮；
- 每次增加 30 条；
- 搜索结果仍按目录分别分页；
- 不使用无限滚动。

磁盘历史由主进程建立完整轻量目录索引；展开目录或加载更多时再返回该目录对应批次。不得依赖全局最近 50 条推导目录组。

## 8. 磁盘刷新

- 切入“磁盘历史”时刷新；
- Tab 可见期间每 30 秒轻量刷新目录索引；
- 历史标题右侧提供全局刷新按钮；
- 不长期递归监听所有 Agent 历史目录。

刷新时保留：

- 展开状态；
- 已选会话；
- 当前滚动位置（尽量保持稳定）；
- 已加载批次数量。

选中记录已不存在时才清除选择。

## 9. 目录有效性与操作

历史加载或刷新时检查目录是否存在；执行打开或继续操作时再次确认。

目录失效时：

- 保留原目录组及历史；
- 显示“目录不可用”；
- 禁用“在资源管理器中打开”；
- 继续会话沿用已有的替代目录选择流程；
- 不归入当前工作区或“未知目录”。

目录整行可展开/折叠。菜单提供：

- 展开此目录 / 折叠此目录；
- 在资源管理器中打开；
- 复制完整路径。

不提供虚拟重命名目录或批量删除历史。

历史标题处提供：

- 刷新；
- 全部展开；
- 全部折叠。

全部展开/折叠仅影响当前 Tab、当前筛选中可见的目录。

## 10. 键盘与可访问性

目录行使用可展开按钮语义：

- `Tab` 聚焦；
- `Enter` / `Space` 展开折叠；
- 设置 `aria-expanded`；
- 提供清晰焦点样式。

当前仅单层分组，不实现复杂树形方向键导航。

## 11. 实施顺序

1. 为路径规范化、目录分组、当前工作区排序、未知目录和分页编写失败测试。

3. 为磁盘完整目录索引、目录检索和批次读取编写失败测试。
4. 实现主进程缓存与 IPC，保留现有详情读取和恢复接口。
5. 扩展持久化展开状态并兼容旧快照。
6. 重构右侧本地和磁盘列表为同一目录组交互。
7. 增加目录菜单、目录有效性、刷新和键盘操作。
8. 完成自动测试、类型检查、生产构建和 Electron 实机验证。

## 12. 验收标准

### 自动测试

- 路径大小写和末尾斜杠正确归组，同名不同路径不合并。
- 当前工作区根目录、子目录、其他目录和未知目录按规定排序。
- 组内会话严格按更新时间倒序，收藏不影响顺序。
- 路径命中显示目录全部会话，正文命中只显示匹配会话。
- 筛选计数正确显示命中数与总数。
- 每组默认 30 条，每次加载增加 30 条。
- 磁盘索引覆盖全部可识别会话，不受旧的全局 50 条上限影响。
- 磁盘目录批次严格按 `mtime` 倒序。
- 展开状态按 Tab 分开持久化并兼容旧数据。

执行：

```text
npm test
npm run typecheck
npm run build
```

### Electron 人工验收

1. 本地和磁盘两个 Tab 都按目录分组。
2. 当前工作区组置顶展开，子目录紧随，其余组按最近活动排序。
3. 组内卡片按最近活动倒序，收藏不改变顺序。
4. 搜索目录名、完整路径、标题和正文的行为符合第 6 节。
5. Agent 筛选和 `命中数 / 总数` 正确。
6. 加载更多每次增加 30 条，不影响其他组。
7. 重启后分别恢复两个 Tab 的展开状态。
8. 目录菜单可打开资源管理器和复制路径；失效目录正确禁用打开。
9. 30 秒刷新与手动刷新不重置选择、展开状态和滚动位置。
10. 目录行可通过键盘展开折叠，亮暗主题和 250–400px 右栏宽度下无重叠。

## 13. 实施与验证记录（2026-08-19）

### 已完成

- 本地与磁盘历史均改为单层工作目录分组。
- 路径按 Windows 规则规范化；完整路径决定组身份，同名不同路径不合并。
- 当前工作区根目录、当前工作区子目录、其他目录、未知目录按规格排序。
- 组内会话严格按最后活动时间倒序，收藏不再改变位置。
- 磁盘历史新增完整目录索引和按目录分页 IPC，不再使用全局最近 50 条推导目录。
- 每组默认加载 30 条，“加载更多”每次增加 30 条；本地和磁盘交互一致。
- 搜索支持标题、正文、目录名和完整路径；目录路径命中时显示该组全部符合 Agent 筛选的会话。
- 筛选状态显示“命中数 / 总数”，匹配组自动展开，清空搜索后恢复持久化展开状态。
- 本地与磁盘两个 Tab 分别持久化目录展开状态，数据版本升级至 v5。
- 磁盘 Tab 切入时刷新、停留期间每 30 秒刷新，保留滚动位置和展开状态。
- 目录组菜单支持展开/折叠、资源管理器打开和复制路径；失效目录显示不可用。
- 目录组头支持 `Tab`、`Enter`、`Space` 及 `aria-expanded`。
